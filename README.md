# Homebrew Cuts

Homebrew tap para [Cuts](https://github.com/vigosan/cuts-releases) — app para cortar los mejores momentos de un vídeo largo en clips.

## Instalación

```bash
brew install --cask vigosan/cuts/cuts
```

## Actualización

```bash
brew upgrade --cask cuts
```

## Desinstalación

```bash
brew uninstall --cask cuts
brew uninstall --zap --cask cuts   # elimina también datos de usuario
```
